# Источники
- Озвучка: файл пользователя (ElevenLabs), public/audio/voice.mp3.
- Шрифт субтитров: Titan One (Google Fonts, OFL). В нём нет кириллицы, поэтому для русских букв подставляется Nunito Black (OFL, округлый, ближайший по виду к Titan One), цифры и латиница — Titan One.
- Музыка, ветер, эффекты: синтезированы кодом в scripts/mix.py (Mixkit/Freesound с этой машины недоступны), внешних сэмплов нет.
- Картинка: three.js + Remotion, всё кодом (мир, люди-человечки, камера).
